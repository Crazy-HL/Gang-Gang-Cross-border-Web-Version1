# 管理员后台 v1 设计

## 背景

项目当前已有一个轻量的 `/admin` 页面，主要用于检测任务复核和大模型配置。它还不是完整的运营管理后台，并且前端导航与路由没有完整限制普通用户访问。后端已有 `ensure_admin(user)`，会基于 `user.role == "admin"` 保护管理员接口。

本次 v1 目标是补齐一个可上线前使用的管理员管理台：管理员能查看关键业务表，普通用户无法看到入口，也不能直接访问后台页面或后台接口。

## 目标

- 只有管理员账号可以看到“后台”导航入口。
- 普通用户手动访问 `/admin` 时不能进入后台。
- 后端所有管理员数据接口继续使用管理员权限校验。
- 管理员后台展示核心业务表，方便排查数据、跟进服务、查看用户与报告。
- v1 控制写操作范围，避免误删数据或误改用户权限。

## 非目标

- v1 不做数据删除功能。
- v1 不开放普通管理员直接修改用户角色。
- v1 不做复杂权限系统，例如多级管理员、菜单级授权、审计日志。
- v1 不替代 CRM，只提供项目内关键业务数据的管理视图。

## 推荐方案

采用“运营管理台 v1”方案：前端做管理员入口与路由隔离，后端扩展管理员只读列表接口，页面以标签页和表格为主。保留现有检测任务复核和大模型配置编辑能力，其余模块先只读展示。

这个方案优先解决当前最影响运营的问题：管理员看不到全局业务数据、普通用户能看到后台入口、服务报告和用户中心数据排查不方便。危险操作先不开放，后续再增加工单状态处理、用户角色管理和审计记录。

## 页面结构

`/admin` 页面改为管理台布局，包含以下标签页：

- 概览：展示用户数、检测任务数、报告数、服务需求数、未读消息数、待复核任务数。
- 用户：展示用户 ID、手机号、昵称、角色、注册时间、检测任务数、服务需求数。
- 检测任务：展示任务 ID、用户、标题、平台/市场、状态、风险等级、复核状态、创建时间，并保留人工复核操作。
- 报告：展示报告 ID、来源类型、标题、用户、风险等级、风险分、生成时间、查看入口。
- 服务需求：展示申诉/TRO 类型、平台、标题、联系人、用户、状态、创建时间、关联报告入口。
- 消息：展示消息标题、用户、类型、是否已读、创建时间。
- 大模型配置：沿用现有配置面板，但用户侧文案不能出现 GPT，应保持“港港跨境AI”。

页面风格应偏运营工具：信息密度高、表格清晰、筛选明显、颜色克制，避免营销页式大卡片。

## 权限设计

前端：

- `SiteHeader` 根据当前登录用户角色过滤导航项。
- `后台` 入口仅在 `user.role === "admin"` 时显示。
- `/admin` 路由增加 `requiresAdmin` 元信息。
- 路由守卫加载当前用户后判断角色；非管理员跳转到 `/dashboard` 或展示无权限状态。

后端：

- 所有 `/api/admin/*` 接口必须依赖当前登录用户。
- 管理员接口统一调用 `ensure_admin(user)`。
- 普通用户访问管理员接口返回 403。

前端隐藏入口只用于体验，真正权限必须以后端 403 为准。

## 后端接口

新增或扩展以下接口：

- `GET /api/admin/overview`
- `GET /api/admin/users`
- `GET /api/admin/jobs`
- `GET /api/admin/reports`
- `GET /api/admin/service-requests`
- `GET /api/admin/notifications`
- `GET /api/admin/model-config`
- `PUT /api/admin/model-config`
- `PATCH /api/admin/jobs/{job_id}/review`

已有接口可复用，不重复实现。列表接口 v1 返回最近数据即可，默认限制数量，避免一次拉取过大数据。每个列表支持基础搜索和筛选参数时优先在后端实现；如果当前数据量不大，也可先前端筛选，但接口结构要为后续后端分页留位置。

## 数据展示规则

- 用户手机号在管理员后台默认完整展示，方便运营联系和排查账号。
- 服务需求联系人默认完整展示，方便跟进客户。
- 报告来源需要区分：侵权检测、平台申诉、TRO 和解。
- 不同报告类型使用不同标签颜色，但保持同一套表格风格。
- 与大模型相关的用户可见文案统一写为“港港跨境AI”。

## 错误处理

- 未登录访问 `/admin`：跳转登录页，并带上 redirect。
- 普通用户访问 `/admin`：跳转用户中心，必要时显示“暂无权限访问后台”。
- 后台接口返回 403：页面显示无权限提示。
- 列表加载失败：当前标签页显示错误提示和重试按钮，不影响其他标签页。
- 单个任务复核失败：保留当前输入，提示稍后重试。

## 测试与验收

后端：

- 普通用户访问管理员接口返回 403。
- 管理员访问用户、报告、服务需求、消息列表返回结构正确。
- 任务复核仍能更新 `review_status` 和 `review_note`。

前端：

- 普通用户登录后看不到“后台”导航。
- 管理员登录后能看到“后台”导航并进入 `/admin`。
- 普通用户手动打开 `/admin` 不能看到后台表格。
- 管理员后台各标签页可加载数据，空数据和加载失败状态可见。
- 前端构建通过。

## 后续增强

- 服务需求状态流转：待处理、跟进中、已联系、已关闭。
- 用户角色管理：只允许超级管理员修改。
- 管理操作审计日志。
- 后端分页、排序和组合筛选。
- 导出 CSV 或 Excel。
